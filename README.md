# Corrida Noturna da Ponte Estaiada

Sistema desenvolvido em Python para gerenciar inscrições e resultados da Corrida Noturna da Ponte Estaiada, organizada pela Assessoria Passo Certo, em Teresina-PI.

## Objetivo

Automatizar o cálculo das inscrições, a classificação dos corredores e a verificação de premiações.

## Tecnologias

- Python 3
- Git e GitHub
- Visual Studio Code

## Etapas do projeto

### Versão 0.1

- Configuração do ambiente de desenvolvimento.
- Inicialização do repositório Git.
- Estrutura básica da aplicação.
- Documentação inicial.

### Versão 1.0

- Inscrição de corredores.
- Cálculo do valor da inscrição.
- Classificação por faixa etária.
- Geração do código do corredor.
- Conversão do tempo e cálculo do pace.
- Verificação da premiação.
- Menu interativo e resumo da sessão.

## Como executar

No terminal, dentro da pasta do projeto:

```powershell
py -3 main.py
```

## Dependências

A Etapa 1 utiliza apenas recursos da biblioteca padrão do Python.
